## Short description

Connect the ToolBraid browser extension to your AI tools on Windows.

## Description

Keep building while your AI helps with the browser work around your project. ToolBraid Companion connects the separately installed ToolBraid extension in Microsoft Edge or Google Chrome to compatible AI clients on your Windows PC.

Read permitted pages, inspect developer community conversations and prepare replies without moving your workflow into another chat. On supported sites and browsers, ToolBraid can discover and use native WebMCP tools. Standard browser tools remain available independently of native WebMCP support.

Connect or disconnect browser registrations from a native Windows window. Check connection distinguishes configuration or launcher issues from a disconnected extension or an unselected page. It performs no browser actions or model requests and omits page addresses, titles, credentials, local paths and raw errors from its report.

Chat inside the extension is optional. Continue in your existing Codex session or another compatible local MCP client. Integrated chat requires a separate Codex installation and your own supported ChatGPT account. Other subscriptions and local models are configured in their supported external clients, not through a universal ToolBraid sign-in.

ToolBraid is free to use. No AI model, account, subscription or API credits are included. The extension is installed separately; this app does not grant site access. Browser control starts paused. Enable only the sites and tools you intend to use. External clients have their own approval rules; integrated chat asks before browser mutations. Pausing cannot undo an action already sent.

Local transport does not mean all processing stays local: your AI client or provider may receive requested page content and tool results. Read the data-handling policy before enabling access. Disconnect browsers before uninstalling. Local connection and conversation data are retained; remove them separately only when no longer needed.

## Feature bullets

- Connect and disconnect public browser registrations without administrator access.
- Check the bundled runtime, configuration, MCP handshake and extension status.
- Use native site WebMCP where supported and browser tools on permitted pages.
- Keep chatting in your existing MCP client; integrated chat is optional.
- Inspect rendered X replies/mentions, draft responses and use opt-in quiet monitoring in the extension. Monitoring does not send automatic replies.
